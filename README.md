# VOIDBREAKER

Мобильный веб-экшен-слэшер в космической готике (вид 3/4). **Вся графика, анимация, интерфейс, музыка и звук создаются кодом**: в репозитории нет ни одной модели, текстуры, шрифта или аудиофайла. Даже иконки PWA рисуются при сборке.

Здесь собран играбельный вертикальный срез **Зоны 01 «Собор Падших Звёзд»**: 6 этапов, 2 Стража и босс Иерофант Скорби. Он закрывает объём MVP из `VOIDBREAKER_Concept.md` §9 и роадмапа `VOIDBREAKER_Tech.md` §29.

Дизайн-документы лежат в корне репозитория:

- `VOIDBREAKER_Concept.md` — концепция;
- `VOIDBREAKER_GDD.md` — геймдизайн;
- `VOIDBREAKER_Tech.md` — техническая архитектура.

## Быстрый старт

Нужен Node.js 20+ (CI работает на Node 22).

```bash
npm ci
npm run dev        # http://localhost:5173
```

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite с HMR |
| `npm run build` | продакшен-сборка в `dist/`: манифест, иконки и service worker |
| `npm run preview` | раздаёт собранный `dist/` |
| `npm run typecheck` | TypeScript strict: игра, тесты и инструменты сборки |
| `npm test` | юнит-тесты (Vitest) |
| `npm run smoke` | e2e-дым на собранной игре (Playwright, Chromium); перед запуском нужен `npm run build` |
| `npm run check` | typecheck, затем test, затем build |

Сборка весит около 1.1 МБ, из них около 270 КБ — gzip-JS. Бюджет — 2 МБ, CI его проверяет.

## Управление

| Действие | Клавиатура и мышь | Тач | Геймпад |
|---|---|---|---|
| Движение | WASD / стрелки | плавающий стик (левая половина экрана) | левый стик |
| Атака / комбо | ЛКМ, J, Enter | кнопка атаки | X / □ |
| Заряженный удар | удерживать атаку | удерживать кнопку атаки | удерживать X / □ |
| Рывок | Пробел, Shift, K | кнопка рывка или свайп по правой половине | A / ✕ |
| Способности Q / E / ульта R | Q·E·R или U·I·O | кнопки способностей | LB / RB / триггеры |
| Пауза | Esc, P | кнопка паузы | Start |

Главные приёмы:

- **Идеальное уклонение.** Рывок в последние 0.15 с перед ударом включает «Мгновение Пустоты»: мир замедляется, следующий удар критический.
- **Слом стойки и казнь.** Когда стойка элитного врага сломана, удар казнит его.
- **Ранг комбо D…SS.** Растёт от разнообразных ударов, пока вас не задели, и увеличивает награду.

Раскладку тач-кнопок, автоприцел, тряску, вспышки, режим для фоточувствительных, штриховку телеграфов и режим «История» можно изменить в настройках (GDD §21).

## Параметры URL для разработки

| Параметр | Пример | Действие |
|---|---|---|
| `stage` | `?stage=1-3`, `?stage=boss1` | сразу открыть бой на этапе |
| `wave` | `?stage=1-6&wave=2` | перейти к нужной волне |
| `god` | `?stage=boss1&god` | бессмертие |
| `screen` | `?screen=hub`, `map`, `settings` | открыть экран меню |
| `q` | `?q=low`, `medium`, `high` | зафиксировать качество (автоподстройка отключается) |

Объекты для отладки в консоли: `window.__app` (автомат экранов и сохранение) и `window.__vb` (`game`, `battle`, `world`).

## Что реализовано

**Бой (GDD §5, §14)**

- Комбо из 4 ударов, шквал, выпад после рывка и заряженный удар.
- Рывок с кадрами неуязвимости и идеальное уклонение («Мгновение Пустоты»).
- Автоприцел с магнетизмом, стойка, слом стойки и казни.
- Резонанс и ульта, ранг комбо.
- Ощущение удара: hitstop не дольше 120 мс за любые 250 мс, тряска, кик камеры, зум-панч, вибрация, частицы, шлейфы, ударные волны.

**Способности (GDD §6)**

- Серп Луны, Фазовый шаг, Гравитационный колодец и ульта Затмение.
- Уровни I–III и мутации A/B.

**Враги (GDD §9)**

- Пять типов: Шипник, Жнец, Око, Обсидиановый голем, Аколит Хора.
- Элитные аффиксы: Ускоренный, Взрывной, Зеркальный, Вампир.
- Директор волн с порталами и токенами атаки.

**Стражи и босс (GDD §11, Tech §17)**

- Система паттернов на таймлайне. Телеграф перед каждым ударом длится не меньше 0.8 с, это проверяют тесты.
- Страж Врат и Звонарь.
- Иерофант Скорби в две фазы:
  - кольцевые волны с разрывами, кадила с дымом, призыв хора с щитом, падение колокола;
  - во второй фазе арена обрушается в крест-мост над бездной, и он бросает кадила по мостам;
  - есть интро-пролёт камеры и кинематографичная смерть.

**Мета (GDD §3, §8)**

- Святилище: 4 ветки статов по 40 уровней с вехами, Кузня оружия, способности, реликвии, архив лора.
- Карта созвездий: ★-рейтинг этапов, врата босса открываются за 12 из 18 звёзд.
- Награды за этап считаются по формулам GDD.
- Сохранение в `localStorage` с контрольной суммой, записью через временный ключ и миграциями. Экспорт и импорт — строкой base64.

**Рендер (Tech §4–§7, §19, §20)**

- Three.js на WebGL2, фасеточная геометрия с цветом в вершинах.
- Обсидиановый matcap-материал, мокрый пол с отражениями-пятнами света.
- Риговые батчи: кости хранятся в float-текстуре, на каждый тип рига один draw call.
- Небо-шейдер с чёрной луной, свой dual-Kawase bloom и uber-пост: ударные волны, ACES, леттербокс, «иней».

**Анимация (Tech §8)**

- Клипы ключевых поз с кроссфейдами и событиями.
- Процедурная походка двуногих и многоногих.
- Ткань и цепи на Верле.

**Звук (Tech §21)**

- Синтез на Web Audio: SFX один раз запекаются через `OfflineAudioContext`.
- Генеративная музыка: слои A–D переключаются по интенсивности боя.
- Хор из формант, колокола из партиалов, сгенерированная реверберация, «голос» Каэлис.

**UI (Tech §22)**

- HUD на Canvas со штриховым процедурным шрифтом.
- Меню на DOM и SVG поверх живой 3D-сцены, переходы диагональным «разрезом».
- Учтены safe-area и альбомная ориентация.

**PWA (Tech §27)**

- Манифест, PNG- и SVG-иконки (включая maskable) и service worker генерируются плагином `tools/pwa-plugin.ts`.
- После первого запуска игра работает офлайн.

## Архитектура

```
src/
  core/     ГПСЧ (mulberry32), математика, шина событий, пулы, шум, три шкалы времени
  data/     баланс и контент: герой, оружие, feel-профили, враги, способности, этапы, арены, лор
  gen/      генераторы: GeomBuilder и примитивы, процедурные текстуры, персонажи, арены зоны
  render/   рендерер, материалы, риговые батчи, небо, пост-обработка, ткань
  anim/     скелеты, клипы, локомоция, Верле, «кукла» персонажа
  world/    симуляция боя: герой, враги, бой, арена, камера, ранг, способности, директор волн
    enemies/  ИИ пяти врагов зоны 1
    boss/     таймлайн паттернов, Стражи, Иерофант
  vfx/      частицы, шлейфы, кольца, телеграфы, обломки, свет
  audio/    синтезатор, рецепты SFX, движок, генеративная музыка
  game/     игровой цикл, Battle, FeelSystem (все «сочные» реакции подписаны на события), App (экраны)
  meta/     сохранение, прогрессия, настройки
  ui/       HUD, шрифт, иконки, экраны меню
  input/    тач, клавиатура, мышь, геймпад и буфер ввода (150 мс)
tests/      юнит-тесты Vitest
scripts/    smoke.mjs — e2e-дым на Playwright
tools/      pwa-plugin.ts — манифест, иконки и service worker при сборке
```

Ключевые принципы:

- **Детерминизм.** Сид этапа задаёт арену, сид врага — модель. Симуляция идёт с фиксированным шагом 60 Гц, мир и герой живут в разных шкалах времени.
- **Данные отдельно от кода.** Мувсеты, профили ощущений, волны и паттерны боссов описаны в `src/data` и `src/world/boss`.
- **Реакции — подписчики.** `FeelSystem` и VFX слушают `EventBus`. Симуляция ничего не знает о тряске, звуке и частицах.

## Тесты

`npm test` проверяет:

- детерминизм ГПСЧ и процедурной геометрии;
- формулу урона и формы хитбоксов (круг, дуга, линия, кольцо с разрывами);
- лимит hitstop и замедления;
- ранг комбо и буфер ввода;
- устойчивость ткани на Верле;
- таблицы стоимости статов и наград из GDD §8, звёзды и открытие врат босса;
- миграцию, экспорт и импорт сохранений;
- данные зоны;
- обрушение арены босса;
- корректность паттернов всех Стражей и босса.

`npm run smoke` проверяет собранную игру в Chromium: титул открывается, затем бот проходит начало этапа 1-1, и в консоли не появляется ошибок.
