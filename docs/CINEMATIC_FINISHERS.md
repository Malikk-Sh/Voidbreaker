# Готовая постановка добиваний

Сцены работают автоматически в самой игре. Для просмотра с телефона достаточно открыть игру с одним из параметров:

- `?watch=hierophantEnd` — Иерофант;
- `?watch=killGate` — Страж Врат;
- `?watch=killBell` — Звонарь.

Внизу просмотра есть три кнопки переключения. Нажатие на выбранную сцену запускает её заново и разрешает звук в мобильном браузере. Переключение происходит без перезагрузки страницы. Пересмотры работают на копии сохранения; награды, звёзды и прогресс не меняются. Игра рассчитана на альбомную ориентацию.

## Иерофант

Полная казнь занимает около 10 секунд, короткая — около 8. Герой приседает, прыгает прямо к Иерофанту, разрубает маску, отталкивается от него и приземляется. Взрыв происходит **до** приземления. После посадки остаётся больше двух секунд на обломки и победу; затем показывается загорающаяся звезда.

Бега по цепи, цепи между героем и маской и касания по таймингу в этой постановке нет. Безупречная казнь определяется боем, без отдельного нажатия в кат-сцене. Контакт маски рассчитывается из настоящей позы и длины клинка; звук, локальная вспышка и трещина запускаются маркером клипа после расчёта скелета. Взрыв разбрасывает фрагменты радиально, замедляется и остаётся видимым в полёте героя.

Камера показывает замах с передней четверти Пилота, включая весь клинок. Подготовка замедлена, но за 0.14 с до контакта скорость мира уже обычная: сам разрез быстрый. На контакте — короткая остановка окружения, направленный след, искры и отдача; на взрыве снова slow motion. Движение героя не зависит от боевого hitstop. Все исходные события, в том числе смерть и награда, выполняются однократно и при пропуске.

## Страж Врат

Камера показывает подсечку с той же стороны оси боя. Страж начинает падать на колено **после** контакта с ногой, а не заранее. Затем Пилот прыгает к шлему и наносит отдельный читаемый удар. Клинок касается настоящего якоря шлема, после контакта остаётся план трещины. Герой приземляется, и только потом Страж распадается.

## Звонарь

Сначала виден обход за спину по дуге, затем прыжок и удар по настоящему колоколу. Свет и фиолетовое кольцо начинаются у колокола в момент контакта. Между ударом и распадом оставлена пауза, чтобы увидеть его результат.

У обоих стражей реакции скелета идут по времени Director, а не по замедленному времени боя. В сценах отключены боевая дрожь и походка врага; вспышка последнего боевого удара затухает. При подсечке стопы Пилота опираются на пол. Точки посадки выбираются на проходимых плитках. Титр появляется после начала распада и не перекрывает сам контакт. После распада остаются две секунды заключительного плана. Обычный облёт победы не запускается поверх постановочного добивания, затем открываются награды. Если Страж убит без казни по оглушённому, его план распада длится 3.4 с и также не запускает второй облёт.

## Остальные переходы

Director плавно смешивает позицию, направление, угол обзора и крен соседних планов. При переходе на другую сторону персонажа камера огибает его: прямое смешивание координат проходило сквозь тело. Вход первого сценического клипа захватывает видимую позу до следующего шага мира, включая прежний выпад и отдачу. В интро Иерофанта и подходе к клинку добавлены отдельные позы ходьбы.

Готовая постановка находится в дорожках и клипах игры. Старые настройки предыдущей редакции из браузера не меняют новые финал, добивания стражей и приземление пролога. Редактор остаётся дополнительной страницей `editor.html`.

## Проверки

```sh
npm run typecheck
npm test -- --maxWorkers=4
npm run build
npm run smoke
npm run finishers
npm run choir
npm run spectacle
npm run studio-test
```

`finishers` проверяет настоящую игровую сцену на 844×390, 740×360 и 1280×720: точность подсечки и основных ударов, видимость клинка и цели, весь замах спереди, обычную скорость мира во время разреза, отсутствие второго облёта, взрыв Иерофанта до посадки, паузу перед распадом стражей, slow motion, одну смерть, пропуск и изоляцию сохранения. Кадры и отчёт сохраняются в `work/finishers/`. Для системного Chromium используется `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`.

Проверки браузера выполняются в эмуляции мобильных размеров. Производительность на физическом телефоне отдельно не измерялась.
