# Хоры — ответный псалом

Статуя в провалах уровня 1-9 теперь участвует в бою. Спустя четыре секунды после начала волны она начинает запоминать места Пилота. На полу остаётся красная метка, от певца к ней проходят золотые ноты. Через 1.3 секунды псалом бьёт по **прежнему месту**, а не преследует игрока.

Метка опасна и для Пилота, и для врагов. Можно собрать толпу на мостике и уйти с метки, оставив врагов под ударом Хора. Идеальный рывок в момент удара возвращает весь аккорд: оставшиеся метки отменяются, фиолетовая волна ранит и оглушает противников, Пилот получает дополнительный Резонанс. На девять секунд Хор перестаёт ставить метки, статуя тускнеет и её пение затихает. Новых кнопок нет: на Android используются стик и обычная кнопка рывка.

В первой волне звучит одна нота, в двух следующих — две с интервалом 0.65 с, в последней — три. После аккорда есть передышка. При открытии меню паузы время не идёт; во время кат-сцены и Раскола метки отменяются. Между волнами, после смерти игрока и завершения уровня псалом не атакует. Геометрия мостика не меняется.

В просмотре добиваний есть ссылка «Играть: Хоры»; прямой вход на уровень — `?stage=1-9`. Это обычный бой, с обычными наградами за прохождение.

Логика находится в `src/world/choir.ts`, подключается только для арены 1-9. `npm run choir` проверяет настоящий бой на мобильных размерах: видимость предупреждения, урон заманенному врагу, возврат нажатием сенсорной кнопки, оглушение, затухание статуи и пения. Модульные проверки дополнительно проверяют задержку, число нот, отмену и удаление системы.
